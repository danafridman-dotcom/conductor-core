# LIVE SMALL

## Назначение
LIVE SMALL — режим аккуратного возвращения к активной торговле
после стабилизации состояния и прохождения STATE_CHECK.

## Предварительное условие
- STATE_CHECK = PASSED
- Нет давления на результат
- Нет желания «отыграться»
- Состояние спокойное и ясное

Без выполнения условий вход запрещён.

## Формат торговли
- Минимальный объём
- 1–2 сделки в день максимум
- Только A+ сетапы
- Без импровизации

## Ограничения
- Без увеличения риска
- Без ускорения
- Без торговли «из интереса»

## Цель этапа
- Проверить устойчивость системы
- Проверить дисциплину в реальном рынке
- Сохранить контроль над состоянием

## Критерий успеха
- Соблюдение правил важнее PnL
- Ошибка = повод остановиться, а не продолжать
