# STABILIZATION — Day 4

## Цель дня
Контроль реакции на упущенные движения.

## Контекст
Рынок может дать движение без тебя.
Это нормально и не требует реакции.

## Разрешено
- Признать упущенное движение без эмоций
- Зафиксировать факт без анализа «почему не я»
- Продолжать следовать системе

## Запрещено
- Погоня за ценой
- Вход «чтобы не упустить»
- Самокритика задним числом

## Фокус
Отсутствие сделки — тоже результат.

## Итог дня
День засчитан, если:
- не было входов из FOMO
- реакция на упущенное движение осталась нейтральной
