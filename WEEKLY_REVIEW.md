# WEEKLY REVIEW CARD

This is the ONLY place where system changes are allowed.

No rule changes during live execution.
No changes during simulation sessions.
Only weekly review can modify the system.

---

## Review Inputs

- Number of sessions
- Rule violations (count + type)
- Execution consistency
- Emotional stability
- Risk compliance
- Drawdown and recovery behavior

---

## Non-Negotiable Questions

1) Did we violate any rule?
2) If yes, why did it happen?
3) Which guardrail failed (EXECUTION / ANTITILT / RISK)?
4) What single change prevents recurrence?

---

## Allowed Changes (only here)

- Tighten rules (more strict)
- Reduce risk
- Reduce max trades
- Add a new filter
- Clarify ambiguous definitions

---

## Forbidden Changes

- Loosening rules after losses
- Increasing risk after losses
- Changing system to “fit” one event
- Over-optimizing based on a single week

---

## Weekly Decision Output

Choose ONE:

- KEEP (no changes)
- TIGHTEN (add restrictions)
- PAUSE (stop trading and review)
