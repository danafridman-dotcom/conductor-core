# SERVER — Conductor (No Telegram)

Цель:
Сервер автономно анализирует рынок (притоки, объёмы, импульсы),
выбирает монеты по строгим правилам и принимает решение
лонг / шорт / пропуск.

Telegram не используется. Только сервер + OKX API.

## Принципы
- Без эмоций
- Только формальные правила
- Логи важнее прибыли
- Фьючерсы 2× допускаются
- Сделки короткие (scalp / momentum)

## Этапы запуска
1. OBSERVER  
   — сбор данных  
   — поиск аномалий (приток, объём, импульс)  
   — логирование  
   — БЕЗ сделок  

2. DECISION ENGINE  
   — формальные правила входа  
   — расчёт риска  
   — симуляция сделки  

3. EXECUTION (позже)  
   — авто-вход минимальным объёмом  
   — жёсткие лимиты  
   — авто-выход  

## Статус
