# LIVE MICRO — Day 7  
## Стабильное исполнение

### 🎯 Цель дня
Проверить способность стабильно исполнять стратегию  
без давления, без суеты и без ожиданий результата.

---

### 🧠 Фокус
- Повторяемость
- Спокойствие
- Автоматизм действий

---

### ⚙️ Формат торговли
- Сделки: короткие
- Вход: строго по сигналу
- Выход: без ожиданий «ещё чуть-чуть»
- Частота: умеренная

---

### 🚫 Запрещено
- ❌ Улучшать стратегию
- ❌ Менять правила
- ❌ Увеличивать объём
- ❌ Лезть без сигнала

---

### ✅ Обязательные условия
- ✔ Каждая сделка записана
- ✔ Нет решений «на ощущениях»
- ✔ Выход выполнен по правилам

---

### 🧾 Самоконтроль
- Было ли напряжение?  
- Хотелось ли нарушить правила?  
- Получилось ли действовать спокойно?

---

### 🟢 Критерий успеха дня
День успешен, если:
- стратегия исполнена без нарушений
- психика стабильна
- результат не влиял на решения
