# DECISION_ENGINE — Ядро принятия решений

## Назначение

DECISION_ENGINE — это центральный модуль системы.
Он принимает **разрешения или запреты** на торговые действия
на основе структурированных данных, поступающих из DATA_LAYER.

DECISION_ENGINE:
- НЕ исполняет сделки
- НЕ управляет ордерами
- НЕ анализирует «вручную»

Он отвечает только на один вопрос:

👉 **МОЖНО ЛИ СЕЙЧАС ДЕЙСТВОВАТЬ?**

---

## Входные данные

DECISION_ENGINE получает данные исключительно из DATA_LAYER:

- агрегированные свечи (1m → 24h)
- рыночные состояния (тренд / флет / импульс)
- волатильность
- объёмы
- аномалии
- статус рынка

DECISION_ENGINE не обращается к бирже напрямую.

---

## Выходные состояния (Decision States)

DECISION_ENGINE всегда возвращает одно из состояний:

- `ALLOW_TRADE` — разрешено открытие позиций
- `ALLOW_REDUCED` — разрешена торговля с пониженным риском
- `WATCH_ONLY` — наблюдение, без входов
- `BLOCKED` — торговля запрещена

Никаких промежуточных или «серых» состояний нет.

---

## Принцип работы

DECISION_ENGINE работает по принципу **жёстких фильтров**:

1. Получить данные из DATA_LAYER
2. Применить правила допуска
3. Определить текущее состояние
4. Передать решение в EXECUTION_LAYER

Если хотя бы одно критическое правило не выполнено —
состояние автоматически `BLOCKED`.

---

## Ключевые правила допуска (базовые)

Примеры условий, которые могут использоваться:

- Рынок не в экстремальной волатильности
- Нет конфликтов таймфреймов
- Нет аномальных объёмов против позиции
- Глобальный тренд не против локального входа
- Нет активного режима защиты капитала

Список правил расширяется, но логика остаётся неизменной.

---

## Связь с другими слоями

DATA_LAYER → предоставляет данные  
DECISION_ENGINE → принимает решение  
EXECUTION_LAYER → исполняет ТОЛЬКО разрешённые действия

DECISION_ENGINE — это «охранник у двери».
Без его разрешения ничего не происходит.

---

## Гарантии

DECISION_ENGINE обеспечивает:

- отсутствие импульсивных входов
- воспроизводимость решений
- одинаковое поведение системы в одинаковых условиях
- защиту от эмоциональных действий

---

## Статус

DECISION_ENGINE является обязательным компонентом системы.
Любая торговля без него считается недопустимой.
