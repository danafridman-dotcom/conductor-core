# Day 8 — Micro-Capital (1%)

## Purpose
Transition from simulation to live conditions
with minimal financial and emotional exposure.

## Capital Rules
- Risk per trade: ≤ 1%
- Max trades: 1
- No scaling
- No revenge trades

## Execution Rules
- Execute ONLY if system = YES
- Use exact same execution rules as simulation
- No discretion

## Focus
- Emotional response to real money
- Hand, body, breath before and after entry
- Any urge to interfere

## Forbidden
- Increasing size
- “Testing” extra trades
- Compensating losses

## End of day
- Trade taken: YES / NO
- Emotional reaction description
- Rule violations: NONE / LIST
- Verdict: READY / NOT READY
