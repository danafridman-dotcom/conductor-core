# Simulation — Day 4

## Purpose
Controlled execution without money.
Testing execution mechanics without emotional cost.

## Rules
- No real money
- Paper execution only
- Execution ONLY if system = YES
- No manual overrides

## Execution model
- Entry: allowed signal only
- Stop: system-defined
- Take-profit: system-defined
- Position size: fixed paper unit

## What is tracked
- Execution accuracy
- Timing vs signal
- Emotional response AFTER execution
- Desire to interfere

## Forbidden
- Early entry
- Late entry
- “Just one more” adjustments

## End of day
- Executed trades count
- System compliance %
- Emotional deviation notes
