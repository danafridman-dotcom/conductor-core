# Simulation — Day 6

## Purpose
Test system behavior under artificial stress.
Train execution with pressure, without capital risk.

## Stress factors
- Limited decision time
- Multiple signals close together
- Conflicting emotions

## Rules
- Decision must be made within allowed window
- No signal stacking
- One action = one rule set

## What is tracked
- Signal type
- Decision time (seconds)
- Final action (execute / skip)
- Reason (rule-based only)

## Forbidden
- Overthinking
- Re-checking higher TF
- “Just one more look”

## Evaluation
- Was execution clean?
- Was delay justified by rules?
- Did pressure change behavior?

## End of day
- Execution score (0–10)
- One weakness noticed
- One strength noticed
