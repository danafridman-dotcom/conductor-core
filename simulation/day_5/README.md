# Simulation — Day 5

## Purpose
Detect execution errors and human interference.
Expose hidden rule violations.

## Focus
- Where system said YES but action was delayed
- Where system said NO but urge appeared
- Micro-interference (hesitation, doubt, tweaking)

## What is tracked
- Signal appeared (YES / NO)
- Actual action taken
- Delay (seconds / minutes)
- Thought at the moment
- Emotional trigger

## Common traps
- “I’ll wait for confirmation”
- “It looks risky today”
- “Market feels different”
- “I know better this time”

## Rule
- System decision > feeling
- No correction during execution

## End of day
- List of deviations
- Reason category (fear / greed / control / impatience)
- One sentence conclusion
