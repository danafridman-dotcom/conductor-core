# Дирижёрское ядро (Conductor Core)

Это репозиторий **архитектуры** системы «Дирижёр».
Здесь нет торговых сигналов “что делать” — только строгие слои, которые дают порядок мышления.

## Pipeline (порядок обязателен)

1) `CONTEXT.md` — рыночная среда (фон)
2) `STATE.md` — итоговое состояние рынка (LONG / SHORT / NO TRADE)
3) `SIGNALS.md` — что рынок показывает (без действий)
4) `FILTERS.md` — разрешение/запрет исполнения (TRADE_ALLOWED / NO_TRADE)
5) `RULES.md` — правила исполнения (действия только здесь)

## Правило проекта
Каждый слой отвечает только за своё.
Никаких “входов/выходов” в `SIGNALS`, никаких эмоций, никаких догадок.
