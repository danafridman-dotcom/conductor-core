# STATE_CHECK

Назначение: контроль состояния системы перед сменой режима.

## Роль
STATE_CHECK — это фильтр допуска.
Он решает, можно ли продолжать движение дальше по системе.

## Проверки
- Нет нарушений базовых правил
- Нет эмоционального тильта
- Последний торговый день закрыт корректно
- Нет аварийных флагов
- Структура соблюдена

## Результат
- ALLOW — переход разрешён
- HOLD — переход запрещён, требуется стабилизация

## Примечание
STATE_CHECK не даёт торговых решений.
Он только разрешает или запрещает дальнейшие действия.
