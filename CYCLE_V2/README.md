# LIVE_SMALL — Cycle V2

Новый цикл после завершения предыдущего.
Режим: LIVE_SMALL

## Purpose
- сохранить дисциплину
- торговать только по подтверждённым правилам
- без расширения риска

## Gates
- STATE_CHECK: обязателен перед каждым днём
- DECISION: режим LIVE_SMALL подтверждён
